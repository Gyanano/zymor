# 本地记忆面板

`zymor panel` 启动一个只读本地 Web 面板，用于浏览记忆、查看 review 队列、dream 历史与规则检查失败。

## 启动

```bash
zymor panel
zymor panel --port 8766
```

默认监听 `127.0.0.1:8765`，只适合本机使用；不提供登录、远程访问或写入能力。

## 页面内容

- 节点总数、分层统计、健康指标；
- 待 review 节点；
- 最近 dream run；
- 最近规则检查失败；
- 标题/摘要搜索。

## API

- `/`：面板页面；
- `/api/overview`：统计、review、dream 摘要；
- `/api/search?q=...`：检索；
- `/api/rules`：最近规则失败；
- `/api/dreams`：最近 dream run。

所有 API 只读；面板不修改节点内容，也不写检索审计。首次访问时若索引缺失，会重建索引缓存；这不会改变记忆事实源。

## 边界

- 不替代 MCP/CLI；
- 不做多用户权限、云端托管或移动端；
- 不展示完整 L0 原始事件与审计明细；
- 作为可选本地工具，不进入默认启动流程。
